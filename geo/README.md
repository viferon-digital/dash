# Дашборд GEO-видимости

Кого языковые модели называют, когда у них спрашивают про противовирусные
препараты. Данные лежат в Google Таблице, забираются через прослойку на
Cloudflare, отображаются без серверного рендеринга и без внешних библиотек —
как и соседние дашборды проекта.

**Живая цепочка данных:** Google Таблица (лист «Data») → Cloudflare Pages
Function (`/api/geo`) → браузер.

## Что показывает

| Блок | Что отвечает |
|---|---|
| KPI-строка | доля голоса препарата в фокусе, его место в рейтинге, охват ответов, сколько ответов в расчёте, сколько моделей и запросов |
| Рейтинг препаратов | все 14 препаратов в одной шкале; переключатель «доля голоса» / «охват ответов» |
| Конкурентное соседство | с кем фокусный препарат чаще всего называют в одном ответе |
| Где нас не находят | доля ответов с фокусным препаратом по каждому запросу, худшие сверху — это список задач для контента |
| Лояльность моделей | тепловая карта модель × препарат: какая доля упоминаний модели приходится на каждый препарат |
| Динамика по замерам | столбец на замер: высота — сколько ответов, заливка — доля с фокусным препаратом |
| Ответы моделей | таблица с фильтрами, полным текстом любого ответа и выгрузкой в CSV |

Препарат в фокусе выбирается сверху и меняет KPI и три карточки; рейтинг и
лояльность моделей всегда показывают всех, фокусный в них выделен.

Фильтры (период, модель, запрос, «только ответы с фокусным препаратом»)
пересчитывают **всё**, включая KPI и тепловую карту.

Дашборд подхватывает тему системы, имеет собственный переключатель
светлая/тёмная и раз в 15 минут тихо обновляет данные.

## Метрики

Три метрики взяты с листа «Пояснения» — считаем ровно так же, как считает сама
таблица, и цифры на дашборде сходятся с её листами:

| Метрика | Как считается |
|---|---|
| **Доля голоса** | упоминания препарата ÷ все упоминания всех препаратов |
| **Лояльность модели** | то же самое в пределах одной модели: сумма строки в тепловой карте — 100% |
| **Конкурентное соседство** | сколько раз два препарата названы в одном ответе |

К ним добавлена четвёртая, которой в таблице нет:

| Метрика | Как считается |
|---|---|
| **Охват ответов** | в какой доле ответов препарат вообще появился |

Разводить их важно: доля голоса Виферона — 20%, а охват ответов — 37%. Первое
отвечает «какую часть эфира мы занимаем», второе — «в скольких ответах мы
вообще есть». Сумма охватов по препаратам больше 100%, потому что в одном
ответе называют несколько препаратов.

### Неразмеченные ответы

Часть свежих замеров лежит в таблице с пустыми колонками препаратов — их ещё не
размечали. Пустая ячейка это **«ещё не смотрели»**, а не «не упомянут», поэтому
такие ответы не входят ни в один знаменатель: иначе свежий замер выглядел бы
как обвал видимости. Сколько их и за какие даты — написано в баннере сверху, а
в таблице они помечены отдельно.

## Как работает прослойка

`functions/api/geo.js` отвечает на `GET /api/geo`:

1. Ходит в `gviz/tq` Google Таблиц и приводит ответ к стабильной JSON-схеме.
2. Кэширует ответ на edge Cloudflare — Google отдаёт `no-store`, поэтому TTL
   держим сами (`CACHE_TTL`, по умолчанию 900 секунд).
3. Отдельно хранит **последний удачный ответ**. Если Google лёг, отдаётся он с
   заголовком `x-cache: STALE` — дашборд не белеет, а честно пишет об этом.
4. Не пускает ID таблицы в браузер: фронтенд знает только про `/api/geo`.

Полезные заголовки ответа: `x-cache` (`HIT` / `MISS` / `BYPASS` / `STALE`) и
`x-data-source`. Принудительно обновить: `GET /api/geo?refresh=1` — это же
делает кнопка «Обновить».

### Почему тексты ответов не едут в браузер

Колонка «Текст» — это полные ответы моделей, почти четыре мегабайта. Возить их
ради таблицы незачем, поэтому прослойка их не отдаёт: в браузер уходят только
отметки упоминаний, упакованные в битовую маску, — **31 КБ вместо 7,6 МБ**.
Весь журнал целиком оказывается на клиенте, и фильтры пересчитывают всё
мгновенно, не ходя на сервер.

Текст конкретного ответа догружается по одному, когда его открывают:
`GET /api/answer?row=123`, где `row` — номер строки листа, он приходит вместе с
журналом. Такие ответы кэшируются на сутки: сделанный замер не меняется.

## Требования к Google Таблице

* Доступ: «Любой, у кого есть ссылка — читатель». Публиковать в веб отдельно не
  нужно, `gviz` работает по этому же доступу.
* Лист `Data`, первая строка — заголовки:

| Колонка | Что в ней |
|---|---|
| `Дата` | дата замера, `ДД.ММ.ГГГГ` |
| `Текст` | полный ответ модели |
| `Модель` | идентификатор модели, например `openai/gpt-4o-mini` |
| `Запрос` | что спрашивали |
| дальше | по колонке на препарат: `1` — упомянут, `0` — нет, пусто — ещё не размечено |

Препараты берутся из заголовков: чтобы добавить ещё один, достаточно дописать
колонку — код трогать не нужно.

## Структура

```
public/
  index.html            разметка
  assets/styles.css     токены светлой и тёмной темы, компоненты, шкала тепловой карты
  assets/theme.js       тема до первой отрисовки
  assets/app.js         загрузка, фильтры, все карточки, таблица
  data/fallback.json    снапшот журнала на случай недоступности прослойки
functions/
  api/geo.js            прослойка к Google Sheets
  api/answer.js         текст одного ответа
  lib/geo.js            разбор листа, упаковка журнала
scripts/
  snapshot.mjs          обновление снапшота (переиспользует код прослойки)
wrangler.toml           конфиг Pages: каталог сборки и переменные
```

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:8788
npm run snapshot   # обновить public/data/fallback.json
```

## Деплой на geo.viferon.digital

Дашборд живёт в том же репозитории, что и главная, но это **отдельный проект
Cloudflare Pages** — у него свой поддомен.

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** →
   **Connect to Git** → репозиторий `viferon-digital/dash`.
2. Настройки сборки:
   * **Framework preset** — `None`;
   * **Build command** — пусто;
   * **Root directory** — `geo` ← главное отличие от проекта главной;
   * **Build output directory** — `public`.
3. **Settings → Variables and Secrets**: `SHEET_ID`, `SHEET_NAME` (`Data`),
   `CACHE_TTL` (`900`). Значения уже лежат в `wrangler.toml`, в проде их лучше
   продублировать переменными.
4. **Custom domains** → `geo.viferon.digital`. Домен уже в этом аккаунте
   Cloudflare, поэтому запись создастся сама.

Дашборд открыт всем, у кого есть ссылка — как и соседние. Если понадобится
закрыть, поверх ставится **Cloudflare Access** (Zero Trust → Access →
Applications) или переносится `_middleware.js` из проекта главной.
